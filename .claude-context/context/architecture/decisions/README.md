# MicroKit — Cross-module architectural decisions

This directory records significant architectural decisions that span more than one MicroKit module.
Each ADR is immutable once merged; superseded decisions reference the ADR that replaces them.

One file per decision, named `ADR-GLOBAL-NNN.md`, numbered in order of acceptance. Module-scoped
decisions do not live here — they belong to their module's own `.claude-context/`.
